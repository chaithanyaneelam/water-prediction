What this project does

Drinking water potability

Random Forest / Decision Tree / XGBoost classifiers predict whether water is potable, with probability, anomaly flagging (Isolation Forest + physical rules) and a predicted pH when unmeasured.

Irrigation suitability

The standard USSL (salinity × sodium) and RSC classifications computed exactly by formula, cross-checked by a Random Forest trained on 1,090 real groundwater samples, with the classic USSL diagram.

Potability accuracy sits around 65% by design: the nine chemical parameters barely correlate with the label in this dataset. We report what is true rather than tuning on the test set.

Run it yourself

python -m backend.ml.train_all            # train everything (potability + graphs)
python -m backend.ml.load_irrigation_dataset   # import irrigation data (file included)
python -m backend.ml.train_irrigation          # train irrigation model
python run.py                             # serve the whole site

Guideline limits shown are typical WHO / BIS / EPA reference values and are for guidance and charts only. Many samples in the training dataset exceed these limits yet are labelled potable, so limits never create labels or model features. Predictions are statistical estimates from the Kaggle Water Potability dataset and are not a substitute for laboratory analysis.
